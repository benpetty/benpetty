Northwest Local operations platform

Python · Django · HTMX · Postgres · httpx · AWS S3/SES/SNS/SQS · OpenTofu · Fly.io

Internal operations platform and CRM for a licensed cannabis producer; sole engineer.

  • Reverse-engineered two state-traceability vendor portals with no public API by intercepting their SPAs’ XHR traffic; every endpoint is allow-listed by method, path, and body schema.
  • Paged reads must reconcile exactly to the vendor’s reported count. Repeated pages, shifting counts, and early empty pages fail as pagination drift, and rows the vendor silently drops are recovered with per-item filter queries.
  • Each endpoint is a versioned contract with a schema SHA-256. A mismatch opens a drift incident and alerts; once the parser is fixed, archived responses are replayed, ordered so a replay can never overwrite newer live data.
  • Vendor responses are archived to S3 as canonical, content-addressed gzip JSON: SHA-256 keys, exact decimals, If-None-Match conditional writes, no delete permission. A recursive sanitizer strips credentials and signed URLs first.
  • A Postgres row-lock rate limiter behind a custom httpx transport gives the web, worker, and scheduler processes one shared request budget per vendor, with jittered backoff and Retry-After handling. No Redis.
  • Crash-safe scheduler on a Postgres-backed task queue (SKIP LOCKED claims, transactional alert outbox). Inbound email runs SES → S3 → SNS with a dead-letter queue and header-verified threading.

NW Clothing store tooling

TypeScript · React 19 · Hono · Drizzle · Postgres · Zod · Cloudflare Workers · fal.ai · ImageMagick · Shopify GraphQL · Printful

Admin console, AI mockup studio, and fulfillment automation for a print-on-demand apparel store.

  • Admin console (React 19, Hono, Postgres) built on one shared Zod contract. Server responses are typed against it at compile time, the client parses every response at runtime, and a stored draft that no longer parses rolls its transaction back.

  • Deterministic ImageMagick compositor. Alpha-weighted gamma normalization and a duotone CLUT recolor each blank to any colorway without clipping highlights. A ratio of Gaussian blurs gives fold-only shading, a displacement map bends the artwork into the fabric, and heathers are seeded noise blends. The artwork is never regenerated, so logos stay pixel-exact.
  • Job executor with a keyed serial queue that prevents lost updates to step state, bounded-concurrency generation runs, and interrupted-job detection on boot.
  • A Cloudflare Worker cron forwards paid Shopify orders to Printful exactly once: the Shopify order ID becomes Printful’s external_id and is checked before create. Failures are isolated per order and alert by email.

Audeos.fm

Elixir · OTP · Phoenix LiveView · Postgres · Oban · ffmpeg · HLS · MediaMTX · Cloudflare R2 · Fly.io

Multi-channel online radio platform with live DJ broadcasts and chat; sole engineer.

  • Server-rendered “joiner” segments: one ffmpeg filter_complex pass trims and equal-power crossfades each mix into its transition, padded to the 4-second HLS grid. That gives millisecond-precise edits without shrinking segments. Joiners are rendered just in time and deleted once played.
  • Per-channel engine GenServers under a DynamicSupervisor resume mid-segment after a crash by projecting a Postgres-persisted cursor forward from the clock.
  • Spec-correct HLS manifests with a discontinuity sequence and a monotonic media sequence, so players reset their decoders across encoder boundaries.
  • Transcodes survive the VM being killed: segments stream to R2 as ffmpeg writes them, and a retry resumes from the lowest completed segment across all bitrates.
  • Listener analytics from Presence-tracked sessions and generate_series over session intervals. Country is resolved at write time from GeoLite2, and IPs are never stored.

crate-agent

Swift · SwiftUI · Rust · UniFFI · GRDB/SQLite · FSEvents · Chromaprint

macOS companion app for Serato DJ that keeps the library intact when tracks are renamed or moved on disk.

  • Clean-room Rust parser and writer for Serato’s reverse-engineered TLV binary formats (crates, smart crates, database V2). Unknown tags round-trip byte for byte.
  • Library writes queue while Serato is running and are re-validated inside a serialized database write (revision token, process state, target file). Stale updates are dropped rather than overwriting newer state.
  • Moves are detected through FSEvents with persisted event IDs. Renames match by volume UUID and inode, cross-volume moves by size plus partial SHA-256, and dropped events trigger a full reconciliation.
  • Cross-volume moves run as a compensating transaction: exclusive-create copy, SHA-256 verification, rollback if the commit fails, and the source deleted only after commit.
  • AcoustID-compatible Chromaprint fingerprints computed in Rust feed MusicBrainz tagging, behind a reentrancy-safe 1 req/s rate limiter and an undo/redo journal.
